# 平台控制面能力移出_可勾选任务清单

- [x] 默认禁用 `/admin/tasks/runtime`。
- [x] 默认禁用 `/admin/tasks/registrations`。

- [x] 默认禁用 `/admin/tasks/executions`。
- [x] 收敛业务后台权限常量，不再把 `task:dispatch` 作为业务页面入口权限。
- [x] 校验默认 OpenAPI 不出现通用任务派发接口。

## 步骤二：移出配置热重载入口

- [x] 默认禁用 `/admin/settings/reload/candidate`。
- [x] 默认禁用 `/admin/settings/reload`。
- [x] 如保留配置重载，当前明确保留为 ops-only 入口，不进入业务后台。
- [x] 确认配置重载不暴露前端页面。
- [x] 校验内部 CLI 或 ops-only 入口不影响业务后台默认启动。
- [x] 明确配置重载保留形式；本轮按 ops-only 入口验收，未作为业务后台或前端页面交付。

## 步骤三：移出原始日志、安全事件与 IP 封禁能力

- [x] 默认禁用 `/admin/logs`。
- [x] 默认禁用 `/admin/security-events`。
- [x] 默认禁用 `/security/ip-blocks*` 作为业务后台能力。
- [x] 校验业务后台无法通过角色分配获得安全管理能力。
- [x] 校验响应、日志、审计不泄漏密码、token、密钥、完整 IP、完整 user-agent 或底层任务 payload 原文。

## 步骤四：移出系统运行时详情

- [x] 默认禁用系统运行时详情页面能力。
- [x] 只保留必要健康检查给部署或探针使用。
- [x] 确认 `system_overview` 不进入业务后台默认模块。
- [x] 校验默认 OpenAPI 不出现业务后台系统运行时详情。

## 步骤五：收敛业务身份授权面

- [x] 默认不挂载任意 scope CRUD：`/admin/scopes`、`/admin/scopes/{scope_code}`。
- [x] 默认不挂载任意角色详情和角色写入：`/admin/roles/{role_key}`。
- [x] 默认不挂载角色 scope 组合编辑：`/admin/roles/{role_key}/scopes`。
- [x] 业务后台角色列表只暴露预定义业务角色，不返回后端 scope 组合。
- [x] 用户角色分配只能选择预定义业务角色，拒绝 `admin` 等技术角色。
- [x] scope 创建/更新与角色创建/更新/替换 scope 请求不进入业务后台契约联合。

## 步骤六：保留未来业务动作模式

- [x] 后续业务重试、补偿、重发必须新增明确业务接口。
- [x] 业务动作接口由后端内部校验状态、权限、幂等后再派发任务。
- [x] 业务动作请求不接收任意 `job_kind`。
- [x] 业务动作请求不接收任意任务 payload。
- [x] 业务动作结果返回是否受理、业务对象状态、幂等键或业务请求 ID。

## 步骤七：写清 ops-only 原则

- [x] 为未来 `/ops/*` 写清默认关闭原则。
- [x] 为未来 `/ops/*` 写清独立权限原则。
- [x] 为未来 `/ops/*` 写清独立网络入口原则。
- [x] 本轮不把 ops 当业务后台交付。
- [x] 校验平台控制面默认关闭，当前通过单独模块开关与独立权限约束；独立网络入口与网络策略标注为未来原则。
- [x] 独立网络入口或网络策略不作为当前完成项，已标注为未来原则。
- [x] 明确当前 ops-only 仅为默认关闭模块；保留的旧 `/admin/*` 平台路径尚未真实迁移到 `/ops/*` 或 CLI。
- [x] 拆分 ops-only 授权常量，或补测试证明其不会作为业务后台页面入口权限。
