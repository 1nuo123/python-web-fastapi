## 5. 契约确认

- [x] `RuntimeCorsSettings`：运行时 CORS 配置，通过强类型配置控制允许源、方法、头、凭证，生产默认收紧。
- [x] `MigrationJobResult`：迁移任务结果，生产启动前一次性 migration job 成功才允许 app 启动。
- [x] `AdminListPageQuery`：后台分页查询，统一业务后台列表分页、过滤、排序输入。
- [x] `AdminListPagePayload`：后台分页响应，统一分页响应结构，支持 `items`、`page_size`、`next_cursor` 或 `total`。
- [x] `AdminRegressionResult`：后台回归结果，记录测试入口、结果、失败修复与剩余风险。
- [x] 契约使用“公共头字段 + 强类型扩展字段”。
- [x] 扩展字段使用 Pydantic 判别联合。
- [x] 扩展字段包含 `kind`、`schema_version`。
- [x] 启用 `extra="forbid"`。
- [x] 禁止在契约中使用 `dict[str, Any]`、`metadata`、`extra_payload`。
- [x] 外层 `header.kind/schema_version` 与内层扩展类型一致。
