- [x] 定义 `AdminAuditHeader`：业务审计公共头，承载 `kind`、`schema_version`、`operation_name`，与扩展字段一致。

- [x] 契约使用“公共头字段 + 强类型扩展字段”。
- [x] 扩展字段使用 Pydantic 判别联合，包含 `kind`、`schema_version`。
- [x] 启用 `extra="forbid"`。
- [x] 禁止在契约中使用 `dict[str, Any]`、`metadata`、`extra_payload`。
