## 阶段契约

| 英文名 | 中文名 | 中文说明 |
|---|---|---|
| AlertRuleCatalogEnvelope | 告警规则目录信封 | 公共头（`kind`、`schema_version`、`policy_name`）+ 规则列表，`extra="forbid"` |
| AlertRuleEnvelope | 告警规则信封 | 公共头含 `rule_name`、`severity`（warning/critical）、`rule_kind`；外层 `rule_kind` 必须与内层 `detail.kind` 一致 |
| ThresholdAlertRuleDetail | 阈值告警规则扩展 | `kind="threshold_alert"`，字段：`promql_expression`、`threshold`、`for_duration_seconds`、`summary` |
| AbsenceAlertRuleDetail | 缺失告警规则扩展 | `kind="absence_alert"`，用于 ready 掉线/抓取缺失类规则；与阈值规则构成判别联合 |

## 基线六条规则

基线六条规则：5xx 错误率、P95 延迟、`fastapi_runtime_ready` 掉线、`fastapi_log_buffer_flush_total{failed="true"}` 增长、`AUDIT_CRITICAL` 写失败、`fastapi_task_execution_total{outcome="failed"}` 失败率。

## 分步骤执行规划

1. `alert_rule_contract.py`：信封、判别联合、外内一致性校验
2. `alert_rule_catalog_loader.py`：读取 YAML 并经契约模型校验（safe load）
3. `config/observability/alert_rules.yml`：六条基线规则落盘
4. Grafana 面板建议同步：日志缓冲失败、审计失败、任务失败率、饱和度四块面板 PromQL 写入接入说明
5. 部署边界说明：规则文件由外部 Prometheus 挂载引用，应用不承载告警执行

## 关键代码片段

```python
AlertRuleDetail = Annotated[
    ThresholdAlertRuleDetail | AbsenceAlertRuleDetail,
    Field(discriminator="kind"),
]

class AlertRuleEnvelope(BaseModel):
    model_config = ConfigDict(extra="forbid")
    header: AlertRuleHeader
    detail: AlertRuleDetail

    @model_validator(mode="after")
    def validate_rule_kind(self) -> AlertRuleEnvelope:
        if self.header.rule_kind != self.detail.kind:
            raise ValueError("header.rule_kind 必须与 detail.kind 一致。")
        return self
```
