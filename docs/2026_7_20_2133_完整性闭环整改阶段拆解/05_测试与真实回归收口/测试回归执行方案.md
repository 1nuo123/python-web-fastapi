# 测试与真实回归收口 · 执行方案

> 本方案为**硬迁移方案**：一次性重构到最佳实践状态，不保留旧路径兼容层，不做渐进式迁移。
>
> 本文档拆解自《2026_7_20_2133_生产级完整性闭环审查与整改执行方案》的「新增或修改测试」「真实测试」「回归修复」三个小节（对应生命周期第 2-4 步），归并为一个「测试与真实回归收口」阶段，只做结构化归并，不改写原始口径与含义。配套可勾选清单见 [测试回归勾选清单](测试回归勾选清单.md)。

## 阶段目标

- 覆盖新增行为、变更行为与回归行为，全部纳入既有分层测试目录与 marker 体系。
- 三个环节固定顺序执行：新增或修改测试 → 真实测试 → 回归修复，不跳步、不并行跨步。

## 依赖关系

- 前置：Phase 1-4 执行修改全部完成（Phase 1 复审 → Phase 2 审计闭环 → Phase 3 监控指标 → Phase 4 告警基线）。
- 后继：文档回归阶段（生命周期第 5 步）。

## 步骤一：新增或修改测试

覆盖新增行为、变更行为与回归行为，全部纳入既有分层测试目录与 marker 体系：

1. `test/unit_test/test_log_buffer_dispatcher_unit.py`：审计关键即时落库、失败计数、stdout 降级、普通路径回归（修改）
2. `test/unit_test/test_prometheus_metrics_registry_unit.py`：四类新指标记录/渲染/开关/标签白名单（修改）
3. `test/unit_test/test_alert_rule_catalog_unit.py`：规则加载与指标名交叉校验（新增）
4. `test/unit_test/admin_audit/test_admin_audit_query_unit.py`：新动作枚举查询与映射（修改）
5. `test/contract_test/test_metrics_runtime_contract.py`：1.1 版本、开关、一致性、未知字段拒绝（修改）
6. `test/contract_test/test_alert_rule_contract.py`：判别联合、`extra="forbid"`、外内一致（新增）
7. `test/contract_test`（日志契约）：`persistence_priority` 字段与版本升级行为（修改）
8. `test/integration_test/test_audit_crash_safety_integration.py`：真实 PostgreSQL 下强制终止进程，验证关键审计事件已落库、普通日志允许窗口丢失（新增，`postgres` + `integration` marker）
9. 既有安全/任务集成测试补充指标断言点（修改）

## 步骤二：真实测试

统一入口与执行顺序（每步全绿才进下一步）：

1. `nox -s static`：格式、Ruff、Mypy、import-linter、Bandit 中高危、pip-audit、detect-secrets、uv lock、双 Compose 解析。
2. `nox -s offline`：物理停止外部服务后的全部离线层（unit/contract/boundary/interface/exception/path/initialization/class_inheritance/convention_usage）。
3. `nox -s regression`：Docker 启动 PostgreSQL/Redis/RabbitMQ 后全量回归，含新增崩溃安全集成测试。

## 步骤三：回归修复

1. 失败逐项定位根因：先判定源码缺陷 / 测试断言口径 / 文档口径，禁止用放宽断言或忽略规则掩盖
2. 源码修复后回跑该失败的定向测试文件
3. 定向通过后回跑所属层（offline 或 regression）
4. 任一源码变更后最终完整回跑 `nox -s static && nox -s offline && nox -s regression`
5. 修复记录追加到本文档发现清单（指原始方案文档的发现清单），状态从 open 迁移到 fixed/verified；不可复验历史不伪造 verified

## 验收点（通过标准）

- 三个会话退出码 0。
- 回归无 skip/xfail/error。
- 总覆盖率 ≥85%、四域（auth/security/task/persistence）≥90%。
- 测试计数不低于既有基线 797 的同口径增长。
- 证据经 `phase_evidence_store` 落 TestRun 记录。

## 关联的全局验收标准

- 质量门禁：`nox -s static`、`nox -s offline`、`nox -s regression` 全部通过，覆盖率不低于既有基线（总体 90.8%、四域 ≥90%）。
- 全局测试约束：静态门禁零容忍（Ruff/Mypy/import-linter/Bandit 中高危/pip-audit/detect-secrets/uv lock）；全量回归禁止 skip/xfail；总覆盖率 ≥85%，auth/security/task/persistence 四域 ≥90%。
