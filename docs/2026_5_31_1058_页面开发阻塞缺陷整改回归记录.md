## 源码契约回归

- `AuthIdentityRepositoryImpl` 现在只把 `AuthScopeOrmModel.enabled=True` 的 scope 写入 `AuthIdentitySnapshot.scopes`；禁用或缺失的 scope 按 fail closed 处理。
- `AuthorizationPolicyEvaluator` 保持现有职责不变，只消费传入的 principal 与 policy，不新增持久化查询。
- `/admin/roles` 的 `AdminRoleListPayload` 已补齐 `page_size`、`offset`、`total`，并继续保持 `kind`、`schema_version`、`extra="forbid"` 与判别联合约束。
- RabbitMQ root vhost 的 Compose URL 使用 `RABBITMQ_VHOST_ENCODED=%2F`；运行时会将空 path、`/`、`//`、`/%2F` 归一为 `/%2F`。
- OpenTelemetry 半接入不在本次整改范围内，本次未修改 OpenTelemetry 配置、桥接或运行时装配。

## 部署文档回归

- 生产部署必须显式使用 `--env-file .env.production.example`、进程环境、Compose Secret 或外部 Secret Manager 注入变量。
- 仓库根目录 `.env` 仅用于本地开发，不作为生产输入。
- `.env.production.example` 只保留占位值，不包含真实 secret 或 local-dev secret。
