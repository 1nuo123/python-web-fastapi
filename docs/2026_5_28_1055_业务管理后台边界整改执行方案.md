# 业务管理后台边界整改执行方案

## 任务目标

交付一份面向后续真实改码与测试回归的后台边界整改方案，把当前 `/admin/*` 明确定义为业务管理后台，移除平台、运维、安全、任务运行时等控制面能力。

完成判定：默认业务后台只暴露用户管理、预定义业务角色分配、业务审计和后续业务模块管理入口；任务中心、配置中心、scope 管理、角色权限组合、原始日志、安全事件、IP 封禁、系统运行时不再进入业务后台。

## 全局约束

- 若文档、图谱、源码冲突，以当前源码为准；`docs/2026_5_26_1849_admin_server_execution_plan.md` 与 `docs/2026_5_27_1330_管理员身份CRUD执行方案.md` 的后台暴露范围已可能过期，回归时必须同步修正。
- 遵守 `docs/standard` 下编码、命名、测试规范；Python 使用 3.11+ 现代类型标注。
- 本轮优先改上游 API、模块清单、配置、应用用例与测试；除业务审计可能需要审计总线或查询适配外，不主动改动基建层核心代码。
- `/admin/*` 只表示业务管理后台；平台、运维、安全控制面后续如保留，必须迁移到默认关闭的 `/ops/*` 或 CLI。
- 默认 `config/app_base.toml` 不启用 `admin_task`、`admin_settings`、`admin_log`、`security_protection`、`system_overview` 作为业务后台模块。
- 通用任务派发、配置热重载、任意 scope CRUD、任意角色权限组合编辑、原始日志、安全事件、指标、IP 封禁、运行时资源不得暴露给业务管理员。
- 业务管理员只允许分配预定义业务角色；角色到后端 scope 的绑定由代码、seed、migration 或 bootstrap 初始化，不由业务后台编辑。
- 用户删除语义统一为停用用户并撤销会话，不做物理删除；接口、响应、文档不得再表达为物理删除。
- 所有 list API 必须具备分页契约，过滤、排序、分页下推 SQL；禁止只在内存中过滤后截断。
- P0 仍需补齐运行基础：CORS 运行时配置、生产一次性 migration job、分页契约。
- 契约必须使用“公共头字段 + 强类型扩展字段”：扩展字段使用 Pydantic 判别联合，扩展字段必须包含 `kind`、`schema_version`，必须启用 `extra="forbid"`。
- 禁止在契约中使用 `dict[str, Any]`、`metadata`、`extra_payload`；外层 `header.kind/schema_version` 必须与内层扩展类型一致。
- 日志、异常、注释和文档使用中文；响应、日志、审计不得泄漏密码、token、密钥、完整 IP、完整 user-agent 或底层任务 payload 原文。

## 验收标准

- 默认配置启动后，业务后台模块清单只包含业务后台允许能力。
- OpenAPI 中不再出现业务后台禁用路径：`/admin/tasks/*`、`/admin/settings/reload*`、`/admin/scopes*` 写接口、`/admin/roles*` 写接口、`/admin/logs`、`/admin/security-events`、`/security/ip-blocks*`、业务后台系统运行时详情。
- `/admin/users*` 保留用户列表、详情、创建、更新、停用、启用、重置密码、分配预定义业务角色。
- `GET /admin/roles` 保留为只读业务角色列表，且不暴露技术 scope 组合编辑能力。
- 新增或改造后的 `/admin/audit-events` 只返回业务管理员可读的业务审计事件，并具备分页。
- CORS、migration job、分页下推具备配置、测试和文档说明。
- 定向测试、接口测试、契约测试、集成冒烟测试与全量 pytest 回归通过。
- 文档回归明确旧管理员服务端方案中的平台控制面暴露范围已过期。

## Phase 4

### 目标

把任务、配置、安全、系统运行时能力从业务后台移出，并为未来业务动作接口留下明确模式。完成后，业务管理员看不到底层任务系统、配置重载、安全策略和运行时资源。

### 依赖

依赖 Phase 1；依赖现有 `endpoint_admin_task`、`endpoint_admin_settings`、`endpoint_admin_log`、`endpoint_security_protection`、`endpoint_system_overview`。

### 模拟用法

```text
POST /admin/orders/{order_id}/retry-sync
POST /admin/reports/{report_id}/regenerate
POST /admin/messages/{message_id}/resend
```

### 契约

| 英文名 | 中文名 | 中文说明 |
|---|---|---|
| BusinessActionRequest | 业务动作请求 | 后续具体业务模块自定义强类型请求，不接收任意 `job_kind` 或任务 payload |
| BusinessActionResultPayload | 业务动作结果 | 返回业务动作是否受理、业务对象状态、幂等键或业务请求 ID |
| OpsOnlyRoutePolicy | ops-only 路由策略 | 平台控制面默认关闭，只能通过单独开关、权限与网络策略访问 |
| SettingsReloadCliCommand | 配置重载 CLI 命令 | 如保留热重载，仅作为内部 CLI 或 ops-only 能力，不进入业务后台 |
