# FastAPI Web 基础设施骨架执行方案

## 任务目标
最终要交付一套可直接运行、可持续扩展、可回归测试的 FastAPI Web 基础设施骨架，严格对齐 [FastAPI统一Web基础设施实现规格](</e:/python_web_fastapi/work/docs/design_docs/FastAPI统一Web基础设施实现规格.md>)、`docs/standard` 三份规范与 [技术选型.md](</e:/python_web_fastapi/work/docs/技术选型.md>)。

完成判定是：
- `src` 下形成可启动的 FastAPI 基础骨架。
- 配置、日志、统一响应、统一异常、请求上下文、鉴权、ORM、缓存、消息/任务、测试基座具备首版落点。
- 自动化测试可真实执行并覆盖核心路径。
- 文档、契约、测试与源码一致。

## 全局约束
- 若文档、图谱、源码冲突，以源码为准，并在回归时标记文档可能过期；当前 `src` 仍是空骨架，`design_docs` 是目标规格，但后续真实改码时仍以实际落地代码为最终事实来源。
- Python 版本固定为 `3.11+`。
- 严格遵守 [命名规范.md](</e:/python_web_fastapi/work/docs/standard/命名规范.md>)、[编码规范.md](</e:/python_web_fastapi/work/docs/standard/编码规范.md>)、[测试规范.md](</e:/python_web_fastapi/work/docs/standard/测试规范.md>)。
- 技术栈固定为：
  - Web：`fastapi` + `uvicorn`
  - 数据建模：`pydantic v2`
  - 配置：`pydantic-settings` + `rtoml`
  - JSON：`orjson`
  - ORM：`sqlalchemy 2.x` + `alembic`
  - 数据库：开发默认 `sqlite`，生产目标 `postgresql`
  - 缓存：本地 `cachetools`，可选 `redis`
  - 消息队列：`rabbitmq`
  - 任务队列：`funboost`
  - 重试：`tenacity`
  - 时间：`whenever`
  - 鉴权：FastAPI OAuth2 Bearer 接入，协议语义遵循 `oauthlib`，令牌实现使用 JWT
  - 测试：`pytest`
- 统一响应、统一错误、任务消息、鉴权主体等稳定结构，必须采用“公共头字段 + 强类型扩展字段”规则。
- 扩展字段必须使用 Pydantic 判别联合。
- 扩展字段必须包含 `kind`、`schema_version`。
- 扩展字段模型必须启用 `extra="forbid"`。
- 禁止使用 `dict[str, Any]`、`metadata`、`extra_payload` 承载稳定协议。
- 外层类型与内层扩展类型必须一致，例如 `response_kind="token"` 时，内部扩展体也必须是 `kind="token"`。
- 所有正式日志使用中文，不允许 `print` 代替日志。
- 所有新增功能必须同步补测试；缺少规定测试项不得视为完成。

## 验收标准
- 应用可通过统一入口启动，并成功挂载健康探针、系统概览、认证接口。
- 统一响应与统一错误输出稳定，响应中可带 `request_id`、`trace_id`、错误码。
- 配置按 `config/app_* + config/modules/* + config/runtime/*` 加载，开发环境可直接运行。
- 鉴权、ORM、缓存、消息/任务、热更新治理均有首版实现与测试覆盖。
- 至少通过单元测试、路径测试、初始化测试、异常测试、边界条件测试、接口测试、契约测试、集成测试中的本次适用集合。
- 设计文档、执行方案、契约、测试结果与源码一致。

### 关键代码片段
```python
from pydantic import BaseModel, ConfigDict, Field


class HealthProbePayload(BaseModel):
    model_config = ConfigDict(extra="forbid")

    kind: str = Field(default="health_probe")
    schema_version: str = Field(default="1.0")
    status: str


class ResponseEnvelope(BaseModel):
    model_config = ConfigDict(extra="forbid")

    code: str
    message: str
    request_id: str
    trace_id: str | None
    data: HealthProbePayload | SystemOverviewPayload | HttpFaultPayload
```
