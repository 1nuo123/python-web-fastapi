# 页面开发阻塞缺陷整改执行方案

## 任务目标
交付一组低复杂度、高优先级整改，修复当前会影响页面开发和生产配置可信度的前三个问题：Scope 禁用未影响授权、`/admin/roles` 分页契约缺失、RabbitMQ vhost 与生产环境变量隔离风险。

最终完成判定：权限语义按 enabled scope 生效，角色列表接口返回完整分页元数据，生产 Compose 不再生成 `:5672//` RabbitMQ URL，且相关测试与文档回归通过；当前真实测试未全部通过，状态见“真实测试”执行记录。

## 全局约束
- 只修前三个问题；OpenTelemetry 半接入问题本次明确忽略，不改代码、不改配置。
- 若文档、图谱、源码冲突，以源码为准；现有历史方案可能过期。
- 遵守 `docs/standard`：类型标注完整，优先使用 Pydantic/dataclass，避免裸 `dict[str, Any]`。
- 契约保持“公共头字段 + 强类型扩展字段”规则。
- Pydantic 扩展字段必须有 `kind`、`schema_version`，必须 `extra="forbid"`。
- 判别联合必须使用 `Field(discriminator="kind")`，禁止 `metadata`、`extra_payload`、宽泛字典扩展。
- 外层 `header.kind`、`header.schema_version` 必须与内层 detail 扩展类型一致。
- 不引入新的权限框架，不做重型重构，优先在现有仓库结构内收口。
- 生产环境变量样例不得包含真实 secret 或 local-dev secret。

## 验收标准
- 禁用 scope 后，用户授权快照不再包含该 scope，依赖该 scope 的授权判断失败。
- `/admin/roles` 响应 detail 包含 `roles`、`page_size`、`offset`、`total`。
- `/admin/roles` OpenAPI、契约测试、接口测试均体现分页字段。
- RabbitMQ root vhost 在连接 URL 中使用 `%2F` 或等价安全归一化，不生成 `:5672//`。
- 生产 Compose 配置使用显式 production env 文件校验，不依赖本地 `.env` 的开发值。
- `uv run pytest -q` 全量通过。
- 文档说明本次不处理 OpenTelemetry 半接入。

## Phase 1
### 目标
修复 disabled scope 仍参与授权的问题。阶段完成后，授权快照只暴露当前 enabled scope，禁用 scope 会立即影响后续授权判断。

### 依赖
依赖 `AuthScopeOrmModel.enabled`、`AuthIdentityRepositoryImpl._build_identity_snapshot`、现有 `AuthorizationPolicyEvaluator` 输入语义。

### 模拟用法
```text
用户持有 role_a，role_a 绑定 scope_a。
管理员将 scope_a.enabled 改为 false。
重新读取用户授权快照：scope_a 不应出现在 scopes 中。
```

### 契约
| 英文名 | 中文名 | 中文说明 |
|---|---|---|
| AuthScopeOrmModel.enabled | Scope 启用状态 | 控制 scope 是否可参与授权，不只是控制后续分配 |
| AuthIdentitySnapshot.scopes | 有效授权范围集合 | 只包含已启用 scope，禁用或缺失 scope 必须 fail closed |
| AuthorizationPolicy.required_scopes | 路由所需授权范围 | 保持现有契约不变，由上游保证 principal.scopes 已过滤 |

### 任务清单
- [x] 在 `auth_identity_repository_impl.py` 中查询角色绑定 scope 的 enabled 状态。
- [x] 将 disabled scope 从 `AuthIdentitySnapshot.scopes` 中排除。
- [x] 明确缺失 scope 行的处理策略为 fail closed。
- [x] 保持 `AuthorizationPolicyEvaluator` 不做额外持久化查询。

### 关键代码片段
```python

    role_scope.scope_code

    for role_scope in user_role.role.role_scopes

```

| AdminRoleListPayload | 管理员角色分页列表扩展 | 增加 `page_size`、`offset`、`total`，继续 `extra="forbid"` |
| AdminIdentityDetailUnion | 管理员身份详情判别联合 | 继续使用 `Field(discriminator="kind")` |

### 依赖
依赖 `compose.yml`、`compose.production.yml`、`RabbitMqMessageGateway._build_connection_uri`。

### 模拟用法
```powershell

```

### 契约
| 英文名 | 中文名 | 中文说明 |
|---|---|---|
| RABBITMQ_DEFAULT_VHOST | RabbitMQ 默认虚拟主机 | Broker 使用的真实 vhost，默认可为 `/` |
| RABBITMQ_VHOST_ENCODED | RabbitMQ URL 编码虚拟主机 | 连接 URL 使用的 path 值，root vhost 使用 `%2F` |
| RABBITMQ_URL | RabbitMQ 连接串 | 不允许生成 `:5672//`，运行时需归一化 |
| .env.production.example | 生产环境变量样例 | 只放占位值，不放真实或 local-dev secret |
