# 安全事件与认证风险_可勾选任务清单

## 步骤 1：安全事件构建链路

- [x] 新增 `SecurityEventBuilder`
- [x] 统一构建安全事件信封并复用现有日志写入链路
- [x] 确保安全事件复用现有日志脱敏能力
- [x] 确保安全事件包含 `request_id`、`trace_id`、`path`、`method`、`policy_name`
- [x] 确保安全事件不包含明文 token、password、secret、IP、User-Agent

## 步骤 2：认证风险信号

- [x] 新增 `RiskSignalGuard`
- [x] 将登录失败接入安全事件
- [x] 将 refresh token reused 接入高风险事件
- [x] 新增 `auth.password_spray_suspected` 风险信号
- [x] 确保 refresh token 复用仍撤销 token session

## 步骤 3：限流与请求体事件接入

- [x] 将 `RateLimitMiddleware` 拦截接入安全事件
- [x] 将 `PayloadGuardMiddleware` 的 `413` 接入安全事件
- [x] 确保超大请求体在 `Content-Length` 与 chunked 路径下均返回 `413` 并生成安全事件

## 步骤 4：可选 Token-IP 绑定

- [x] 新增 `TokenBindingGuard`
- [x] Token-IP 绑定开启时写入 token 摘要与 IP 摘要映射
- [x] Token-IP 不匹配时拒绝请求、删除绑定并生成安全事件
- [x] 确保 Token-IP 绑定默认关闭
- [x] 确保 Token-IP 绑定开启后只对配置声明场景生效
- [x] 确保 Token-IP 不匹配时缓存绑定被清理

## 步骤 5：测试与回归

- [x] 新增安全事件构建测试，覆盖脱敏、摘要字段、request_id/trace_id
- [x] 新增 Token-IP 绑定测试，覆盖默认关闭、开启绑定、IP 摘要不匹配、绑定清理
- [x] 新增安全事件真实 HTTP 接口路径测试
- [x] 回跑认证、刷新令牌复用、日志脱敏、健康检查、metrics 既有测试
- [x] 确保限流、封禁、Token-IP 绑定、payload、认证风险路径符合验收标准
- [x] 确保现有认证、日志、健康检查、metrics、OpenTelemetry 行为不回退
- [x] 确保测试结束后释放数据库 session、缓存连接、HTTP client、锁租约和 TestClient

## 步骤 6：失败修复

- [x] 若安全事件泄露敏感信息，优先修正摘要与脱敏链路
- [x] 若 Token-IP 绑定误拦截，修正适用策略、可信代理 IP 解析和摘要维度
