# 契约与运行时配置冻结_分步骤执行方案

## 阶段目标

冻结统一风控/流控、安全事件、限流策略、IP 封禁、Token-IP 绑定、SSRF 校验的安全契约；同时冻结独立分布式锁契约、统一密钥管理契约，并明确 `runtime.security`、`runtime.distributed_lock`、`runtime.key_management` 三个独立配置入口。

## 全局约束

- 若文档、图谱、源码冲突，以当前源码为准，历史文档可能过期。
- 必须遵守 `docs/standard/编码规范.md`、`docs/standard/测试规范.md`、`docs/standard/命名规范.md`。
- 本次不引入完整 SIEM、WAF、规则引擎或审计平台；安全事件复用现有结构化日志/事件链路扩展。
- 分布式锁必须作为独立基础设施管理，不挂靠安全防护模块；安全防护、密钥管理、任务调度等模块只能通过 Provider 消费锁能力。
- 密钥轮转必须纳入统一密钥管理基础设施，不允许在业务模块内各自实现轮转、密钥环、当前密钥索引或旧密钥兼容逻辑。
- `runtime.security` 只承载安全防护策略；`runtime.distributed_lock` 和 `runtime.key_management` 是独立运行时配置入口。
- 高频流控计数、临时锁、封禁缓存、Token-IP 绑定状态放缓存；明确 IP 封禁记录必须落数据库。
- UoW 是唯一事务边界；Repository 不得 `commit()`、`rollback()` 或释放外层会话。
- 缓存 key 必须符合 `key_prefix:namespace:segment...`，令牌、密码、密钥、IP、User-Agent 参与 key 构造前必须摘要化。
- 认证、鉴权、限流、封禁、分布式锁关键路径缓存不可用时必须 fail-closed，不得放行。
- 新增契约统一采用“公共头字段 + 强类型扩展字段”。
- 扩展字段必须使用 Pydantic 判别联合，包含 `kind`、`schema_version`，并启用 `extra="forbid"`。
- 禁止用 `dict[str, Any]`、`metadata`、`extra_payload` 承载稳定协议。
- 外层类型与内层扩展类型必须一致。
- 不记录明文密码、Bearer、JWT、refresh token、secret、完整请求体、完整 URL 查询串。
- IP、User-Agent、token、host 相关标识默认只保存摘要。
- Token-IP 绑定只做可选高风险策略，不作为全站默认强制策略。
- 日志、异常、注释使用中文；不得使用 `print`。
- 测试必须覆盖资源释放，不能通过跳过测试、放宽断言或回退实现规避失败。

## 契约冻结

| 英文名 | 中文名 | 中文说明 |
|---|---|---|
| SecurityRuntimeEnvelope | 安全运行时信封 | 外层配置入口，`detail.protection` 承载 flow_control、risk_control、ip_block、token_binding、outbound_url_safety |
| SecurityRuntimeHeader | 安全公共头 | 包含 `kind`、`schema_version`、`mode`、`enabled`、`policy_name` |
| FlowControlRuntimeDetail | 流控扩展字段 | 定义默认限流、失败模式、策略集合 |
| DistributedLockRuntimeEnvelope | 分布式锁运行时信封 | 独立定义锁后端、租约时长、等待时长、失败模式 |
| DistributedLockLease | 分布式锁租约 | 表达锁 key 摘要、owner、过期时间、释放状态 |
| KeyManagementRuntimeEnvelope | 密钥管理运行时信封 | 独立定义密钥后端、密钥族、用途、轮转策略、有效密钥数量 |
| ManagedKeyFamilyEnvelope | 托管密钥族信封 | 表达密钥族名称、用途、状态、当前 key id、轮转策略 |
| KeyRotationPolicyEnvelope | 密钥轮转策略信封 | 定义轮转周期、旧密钥保留数量、旧密钥兼容窗口 |
| KeyRingSnapshot | 密钥环快照 | 表达当前 key id、候选 key id、有效 key 集合摘要 |
| TokenBindingEnvelope | Token-IP 绑定信封 | 定义绑定模式、适用 token 用途、IP 摘要 TTL |
| RateLimitPolicyEnvelope | 限流策略信封 | 以公共头 + 强类型扩展字段描述 path/method/window/limit/key 维度 |
| SecurityDecisionEnvelope | 安全决策信封 | 统一输出 allow/deny/throttle/record_only 与处置动作 |
| SecurityIpBlockEnvelope | IP 封禁信封 | 定义封禁记录、状态、释放原因和摘要字段 |
| SecurityEventEnvelope | 安全事件信封 | 定义安全事件类型、严重级别、决策、请求链路字段和摘要字段 |
| OutboundUrlSafetyEnvelope | 出站 URL 安全信封 | 定义允许 scheme、禁止地址段、metadata IP 阻断策略 |

## 分步骤执行

### 步骤 1：冻结安全防护运行时契约

- 新增或扩展安全防护运行时信封，只允许 `runtime.security` 承载 flow/risk/ip_block/token_binding/outbound_url 配置。
- 使用公共头字段 + 强类型扩展字段，扩展字段必须包含 `kind`、`schema_version`，并启用 `extra="forbid"`。
- 保证外层 `mode` 与内层 `kind` 一致，不一致时校验失败。

### 步骤 2：冻结独立分布式锁契约

- 新增 `distributed_lock_contract.py`。
- 冻结 `DistributedLockRuntimeEnvelope` 与 `DistributedLockLease`。
- 明确 `runtime.distributed_lock` 是独立运行时配置入口，不挂靠安全防护模块。
- 锁 key 必须使用摘要片段，缓存或 Redis 不可用时关键路径 fail-closed。

### 步骤 3：冻结统一密钥管理契约

- 新增 `key_management_contract.py`、`key_rotation_policy_contract.py`、`key_ring_contract.py`。
- 冻结密钥后端、密钥族、用途、轮转策略、有效密钥数量、当前 key 与有效 key 快照语义。
- 明确密钥轮转只能由统一密钥管理基础设施实现，业务模块不得直接读写密钥环存储。

### 步骤 4：冻结安全决策、限流、封禁、安全事件、Token-IP、SSRF 契约

- 新增 `security_decision_contract.py`、`rate_limit_policy_contract.py`、`security_event_contract.py`、`security_ip_block_contract.py`、`outbound_url_safety_contract.py`、`token_binding_contract.py`。
- 安全事件不得包含明文 token、password、secret、IP、User-Agent、完整请求体或完整 URL 查询串。
- Token-IP 绑定默认关闭，只作为可选高风险策略。
- outbound URL 安全契约必须支持拒绝本机、内网、link-local、metadata IP。

### 步骤 5：冻结运行时配置文件

- 修改 `config/runtime/security_runtime/*`，补充 flow/risk/ip_block/token_binding/outbound_url 默认策略。
- 新增 `config/runtime/distributed_lock_runtime/*`。
- 新增 `config/runtime/key_management_runtime/*`。
- 修改 `app_settings_loader.py`，校验并加载三个独立入口。

### 步骤 6：补齐契约测试与配置校验

- 新增契约测试，覆盖公共头字段、强类型扩展字段、判别联合、extra forbid、外内类型一致。
- 配置中的 TTL、窗口、锁租约、轮转周期均必须大于 0。
- 解析失败、字段越界、扩展字段未声明、外内类型不一致均必须失败。

## 校验点

- `runtime.security` 可解析 flow/risk/ip_block/token_binding/outbound_url 配置。
- `runtime.distributed_lock` 可独立解析锁后端、租约、等待、失败模式配置。
- `runtime.key_management` 可独立解析密钥后端、密钥族、用途、轮转策略配置。
- 契约外层 `mode` 与内层 `kind` 不一致时校验失败。
- 扩展字段出现未声明字段时校验失败。
- 配置中的 TTL、窗口、锁租约、轮转周期均必须大于 0。

## 阶段验收点

- Redis/cache 不可用时，认证节流、通用限流、分布式锁、封禁判断均 fail-closed。
- 分布式锁可在安全防护之外独立初始化、独立测试、独立复用。
- 安全防护代码不直接创建 Redis 锁，只依赖 `DistributedLockProvider`。
- 密钥管理可在认证、安全防护之外独立初始化、独立测试、独立复用；URL 签名不作为本轮运行时接入口径。
- 业务代码不直接读写密钥环存储，只依赖统一密钥管理服务读取当前 key 或有效 key 快照。
- Token-IP 绑定开启时，异常 IP 使用 token 会拒绝、清理绑定并生成安全事件。
- 日志、安全事件、指标中不出现明文敏感信息。
- 生产环境继续关闭公开 OpenAPI，并启用 HSTS/CSP。
