## 步骤 5：补齐 HTTP 契约、路由与权限

- [x] 新增 `endpoint_admin_task` 契约与路由 provider。
- [x] 任务查询接口要求 `admin + system:read`，任务派发接口要求 `admin + task:dispatch`。
- [x] 对 `limit` 做 `1..200` 边界约束。

## 步骤 6：阶段校验

- [x] `GET /admin/tasks/executions` 可按状态、job kind、limit 查询。
- [x] `GET /admin/tasks/executions/{task_id}` 对不存在记录返回 404。
- [x] 任务未启用时，`POST /admin/tasks/dispatch` 返回明确错误，不写入半成品任务。
- [x] handler 未绑定时，`POST /admin/tasks/dispatch` 返回明确错误，不写入半成品任务。
- [x] `payload_json` 不符合注册 payload model 时返回 422 或业务契约错误。
